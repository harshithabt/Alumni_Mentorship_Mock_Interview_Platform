# Lab 3 – Component Modelling & Architectural Pattern Selection

---

## PROBLEM STATEMENT #06 

## Alumni Mentorship & Mock Interview Platform

---

This lab focuses on selecting a suitable architectural style and developing a UML Component Diagram for the Alumni Mentorship & Mock Interview Platform.

### What was covered

- Architectural style analysis
- Layered Architecture selection
- UML Component Modelling
- Component identification
- Provided and required interfaces
- Component dependencies and interactions
- Security and performance considerations

### Architecture

The system uses a "**Layered Architecture**" consisting of:

- **Presentation Layer** : User Interface
- **Business Layer** : Mentor Matching, Availability & Booking, Interview Assessment, Experience Sharing
- **Data Layer** : Platform Database

### Components

- User Interface
- Mentor Matching
- Availability & Booking
- Interview Assessment
- Experience Sharing
- Platform Database

### Deliverables

- UML Component Diagram (as .png file)
- Architectural Justification (.pdf file)
