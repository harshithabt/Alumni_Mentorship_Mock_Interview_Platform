## Lab 4 - Vibe Coding: Rhythm Tap

The fourth lab focuses on using a Vibe Coding tool to understand, fix, and extend an existing Python game. The implementation adds sound effects, hold notes, BPM-synchronized note spawning, and a game-over grade summary.

**Implemented features**
- Sound effects for PERFECT, GREAT, and OK hits
- Hold notes requiring sustained key presses
- BPM-synchronized note spawning
- Game-over summary with hit counts, accuracy, and maximum combo

**Version Control**
The project was developed by modifying the assigned starter repository https://github.com/SETAPESU26/51_rhythm-tap and maintaining the implementation in a personal GitHub repository. Git commits track the development changes and feature implementation.
The updated source code is included in this Lab 04 submission folder for evaluation.

**Lab 4 deliverables**
- Updated source code
- Before and after gameplay recordings (.mp4 videos of ~10secs)
- Chat history exported as a PDF

See [`Lab04/README.md`](Lab04/README.md) for the detailed instructions, project structure, and deliverable locations.

The dedicated development repository is [51_rhythm-tap](https://github.com/harshithabt/51_rhythm-tap).
